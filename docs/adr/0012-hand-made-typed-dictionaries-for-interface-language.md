# The interface language uses hand-made typed dictionaries, not an i18n library

The front translates its interface with plain TypeScript dictionaries under `src/i18n/` (French as the source, every other language typed `satisfies` the French shape, texts with variables written as typed functions, plurals through `Intl.PluralRules`) read through a `useT()` hook, instead of react-i18next or Lingui. With two languages and no outside translators, a missing or misspelt key failing `npm run build` is worth more than ICU messages, extraction tooling or lazy loading, and it adds no dependency, like the hand-made drag and drop. The keys end up in every component, so switching later is a large mechanical change: reconsider it when translators outside the codebase arrive or the languages grow past a handful, and move to Lingui rather than add features to the hook.
