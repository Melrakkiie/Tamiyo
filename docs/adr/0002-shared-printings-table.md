# Scryfall data for search lives in a shared `printings` table

Filtering the collection by type, subtype or legal format must run in SQL, so the full type line and legalities are kept per `scryfall_id` in `printings`, the only table without a `user_id`. A background `printing.Refresher` fills unknown printings every 2 minutes and refreshes those older than 24 h, so a new card is searchable within minutes and a ban shows up the next day. Deck legality and statistics (`deckinsights`) still call Scryfall on each request without persisting anything: simpler while decks are small, and `printings` is where to read from if that load grows.
